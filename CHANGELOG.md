# Changelog

## 0.1.0

- Package the original H2 RHF/STO-3G implementation as a PowerShell module.
- Separate basis parameters, Boys function, integral evaluation, Fock construction, and SCF solver.
- Add a command-line entry point and structured public API.
- Include a bond-length scan and preserve the original user-validated standalone script.
- Add numerical regression tests and a cross-platform GitHub Actions workflow.
- Document the H2-specific scope and validation status.
